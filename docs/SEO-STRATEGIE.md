## Seitenstruktur (Zielbild)

Eine starke Hauptseite je Cluster mit Unterseiten, nicht eine Seite pro Keyword.

```
/
├── klimaanlagen/ (split-klimaanlagen, multisplit-klimaanlagen, klimaanlage-kosten,
│                  klimaanlage-heizen, herstellervergleich)
├── wartung-klimaanlagen/ (klimaanlage-reinigen, wartungsvertrag)
├── waermepumpen/
├── photovoltaik/ (pv-und-klimaanlage, pv-und-waermepumpe)
├── lueftungsanlagen/
├── smart-home/
├── standorte/ (klimaanlage-heilbronn, klimaanlage-flein, klimaanlage-chemnitz)
└── ratgeber/
```

Hinweis zur Umsetzung: Die Website nutzt derzeit `/leistungen/<slug>` (klimaanlagen, vermietung,
lueftung, finanzierung, foerderung, photovoltaik, stromspeicher). Vorhandene URLs, die schon ranken,
nicht ohne 301-Weiterleitung verschieben. Vor einer Umstellung die Search-Console-Daten (Reiter Seiten)
prüfen.

## Noch offen

Für die Keyword-Analyse fehlt der Search-Console-Export (Leistung → Suchergebnisse, letzte 3 Monate,
Reiter Suchanfragen und Seiten, CSV/Excel). Damit: Keywords auf Position 5–20 finden, Begriffe ohne
passende Landingpage, Kannibalisierung zwischen Seiten. Ziel: Roadmap mit Titel, Meta-Description,
Haupt-/Nebenkeywords, Suchintention und Content-Lücken je Seite.
